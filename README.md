### My Little Demon is an indie videogame developed for the InVideogameJam 2026 organized by Delaguila Games in Catalonia, Spain 

👉  <strong> Main information: </strong>

  <img width="600" height="450" alt="My Little Demon image" src="https://img.itch.zone/aW1nLzMxNDQxMDc2LmpwZw==/347x500/YGbthV.jpg"/>
  
- The game is a basic platformer. You can run, jump, and do wall jumps. There are also checkpoints and basic enemies.
- The game is about the undesired loneliness as a main topic. The scene is set on Halloween night 🎃🌔.
- The main and original mechanic is a shadow of the player that imitates its moves and can kill it if it touches it.
- There are 6 short levels available.
- Narrative based on dialogues inserted between the levels.
- 👾 🎨 32 bits pixel art style.
- 🎮 Accessibility options are available, such as control personalization.
- 🎃 The pumpkins spread around the levels guide your jumps.
- ⌚The estimated duration is 5 to 10 minutes, depending on the player's skills.
- ‼️Storm Warning: The levels are pretty challenging, and the difficulty curve is pretty steep.

⚙️ <strong> Technical information </strong>:
- Developed in Unity.
- Only available for Windows.
